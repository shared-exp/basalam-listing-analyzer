# ابزار تحلیل آگهی‌های باسلام

این پروژه برای بررسی محصولات باسلام و کمک به فروشنده‌ها در بهبود آگهی‌هایشان ساخته شده است. ابزار اطلاعات قابل‌دسترسی محصولات را جمع‌آوری می‌کند، آن‌ها را در فایل Excel قرار می‌دهد و گزارشی برای بررسی وضعیت آگهی و بهتر کردن عنوان و توضیحات محصول آماده می‌کند.

## دسترسی آنلاین

[استفاده از ابزار تحلیل آگهی‌های باسلام](https://testtest007.app.n8n.cloud/form/basalam-listing-analyzer)

## امکانات

- انتخاب دسته‌بندی و مشخص کردن تعداد محصولات برای بررسی
- جمع‌آوری اطلاعات قابل‌دسترسی محصولات باسلام
- ذخیره نتایج در فایل Excel برای بررسی و مقایسه
- تهیه گزارش تحلیلی از اطلاعات جمع‌آوری‌شده
- ارائه پیشنهادهایی برای بهبود عنوان و توضیحات آگهی
- دریافت خروجی‌های پروژه برای بررسی بیشتر

## محدودیت‌های نسخه فعلی

در حال حاضر فقط دسته‌بندی **«خانه و آشپزخانه»** قابل انتخاب است. این نسخه، نسخه اولیه پروژه است و در به‌روزرسانی‌های بعدی دسته‌بندی‌های بیشتری اضافه می‌شود و قابلیت‌های ابزار توسعه پیدا می‌کند.

اطلاعات خروجی نیز به محتوای قابل‌دسترسی صفحات باسلام وابسته است؛ ممکن است برای بعضی محصولات، تمام جزئیات در دسترس نباشد.

## روند استفاده

1. ابزار را از لینک بالا باز کنید.
2. گزینه‌های موجود را انتخاب کنید و تعداد محصولات موردنظر را مشخص کنید.
3. اجرای فرایند جمع‌آوری اطلاعات را شروع کنید.
4. فایل Excel و گزارش خروجی را دریافت و بررسی کنید.

## فناوری‌ها

- **n8n** برای مدیریت و اجرای گردش کار
- **JavaScript** برای پردازش داده‌ها
- **Excel** برای ذخیره و بررسی نتایج
- تولید گزارش برای جمع‌بندی یافته‌ها و پیشنهادها

## اجرای گردش کار در n8n

فایل JSON گردش کار در پوشه `workflow/` قرار می‌گیرد.

1. فایل گردش کار را از مخزن دریافت کنید.
2. در n8n گزینه **Import from File** را انتخاب و فایل JSON را وارد کنید.
3. تنظیمات و دسترسی‌های موردنیاز را بررسی کنید.
4. ابتدا گردش کار را با تعداد کمی محصول آزمایش کنید.

بسته به تنظیمات محیط اجرا و تغییرات احتمالی صفحات باسلام، ممکن است برای راه‌اندازی به تنظیمات بیشتری نیاز باشد.

## ادامه توسعه

این پروژه همچنان در حال توسعه است. در نسخه‌های بعدی، دسته‌بندی‌های بیشتری در دسترس قرار می‌گیرند و قابلیت‌های جدید به ابزار اضافه خواهند شد.

## نکته امنیتی

پیش از انتشار فایل گردش کار، مطمئن شوید هیچ رمز عبور، کلید API، توکن یا اطلاعات محرمانه‌ای در فایل‌ها قرار نگرفته باشد.
